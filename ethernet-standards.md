# Ethernet Standards
* Different standards
* Twisted pair and fiber standards
* IEEE 802.3 committee
  * Manages all types and standards of Ethernet
* Common standards
  * 1000BASE-T
    * Gigabit Ethernet
    * Copper
    * 1 Gbps
  * 10GBASE-T
    * 10 Gigabit Ethernet
    * Copper
    * 10 Gbps
  * 1000BASE-SX
    * Gigabit Ethernet
    * Fiber
    * 1 Gbps
* How the standards work
  * The number is usually related to the speed
    * 1000 is commonly 1000 megabits per second (1 Gbps)
    * 10G would be 10 Gbps
    * (Gbps is Gigabits per second, not the same as GBps which is Gigabytes per second)
  * BASE (baseband)
    * One frequency using the entire medium
    * Broadband uses many frequencies, sharing the medium
  * Media type
    * T is for twisted pair copper
    * F is for fiber
    * SX is short wavelength light
